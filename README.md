# IGZO-ZrO2-Synaptic-CNN

# Device-Aware CNN for Neuromorphic Computing

This project investigates a device-aware convolutional neural network (CNN) framework in which trained neural-network weights are mapped to states derived from synaptic device characteristics.

The objective is to study the effect of device-state constraints on CNN-based pattern classification.

## Project Overview

The workflow combines device-level characteristics with a software-based CNN classification model.
