# Dataset

This folder contains the datasets used for the device-aware CNN experiments.

## Dataset structure

'braille_dataset.csv' — Braille character dataset used for CNN classification.
'model1/' — Device simulation data used for Model 1 device-state extraction and weight quantization.

The device CSV files contain simulated transient/device characteristics used to generate device states for the device-aware CNN evaluation.
